# TwelveTech Media Landing Page

Premium White-Label Web Agency Landing Page.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Tech Stack
- HTML5 / CSS3 (Vanilla)
- GSAP (Animations)
- FontAwesome
- Vite (Dev Server)
